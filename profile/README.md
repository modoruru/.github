# modoru
modoru — is a private Minecraft server with unique concepts and mechanics, all in vanilla spirit.\
The project is comprised of unique and high-quality solutions that provide the best possible experience for players while remaining almost entirely open-source.

## Our projects
We maintain several projects.
- [hitori](https://github.com/modoruru/hitori): a plugin-based framework
- [hitori-ux](https://github.com/modoruru/hitori-ux) and [hitori-resourcepack](https://github.com/modoruru/hitori-resourcepack): 
two main modules using hitori framework providing numerous features and APIs for other modules
- [enji](https://github.com/modoruru/enji): minecraft server deployment tool
